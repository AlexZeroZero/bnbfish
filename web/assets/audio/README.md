# 湖水声景

## 当前背景音乐：岸边来信 / Shore Letter v3
原创 120 秒、72 BPM、3/4 拍器乐。采样钢琴主旋律、尼龙吉他分解和弦、少量弦乐；包含引子、主题、对比段和回归。替换旧版程序合成器音乐。独立开关、后台暂停与渐入渐出保留。
作曲及渲染源文件：tools/compose_lakeside_v3.py。音符谱：release/Bnbfish-v0.25-music-score.json。
乐器音源：Chris Collins 的 GeneralUser GS v2.0.3，https://schristiancollins.com/generaluser.php 。许可允许商业/非商业音乐制作，详见同目录 GeneralUser-GS-LICENSE.txt。APP 仅包含渲染后的录音，不包含 SoundFont。
混音目标 -20 LUFS，峰值上限 -2 dBTP；钢琴与吉他使用轻量房间反射，无鼓点、人声或持续合成器长音。

## 宁静背景音乐
still-water.ogg / still-water.wav：项目原创程序合成器乐《静水》，48 秒，40 BPM，五声音阶、柔和长音与拨弦声。作曲源文件 tools/compose_music.py。未使用第三方音乐采样，可随本项目修改和分发。与真实水声独立开关，默认关闭。

## 湖畔小夜曲 / Lake Reverie v2
Original 32-bar instrumental composed in `tools/compose_reverie.py` for Bnbfish.
112.94 seconds, 68 BPM, stereo; introduction, two contrasting melodic passages,
reprise and sparse ending. Software-synthesized soft piano and sustained backing,
humanized timing/velocity and stereo reflections. No third-party instrument samples.
OGG is the shipped asset; WAV is a production master excluded from the APK.

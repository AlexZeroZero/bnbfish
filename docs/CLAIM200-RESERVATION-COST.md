# 永久未领取版本：实测费用与发布限制

本地模拟，使用真实编译的候选合约；不是主网实际扣费。按 Gas 价格 0.05 Gwei 换算，随价格线性变化。物种分布与冷/热存储不同会改变实际消耗，以下是样本，不是最高限额。

抛竿约 260,462–353,518 Gas（另加 0.00001 BNB 协议费）；领取样本约 267,820–284,920 Gas，由领取玩家支付。部署主网 RPC 估算约 13,323,428 Gas，在采样价格下约 0.0006661714 BNB。

首个低参与批次的分配费用可能超过该批协议费收入，不能承诺每一批都收支平衡。要实现平台不垫付，执行服务必须受累计协议费预算限制；预算不足时应保留“等待验证”，不能假报“未领取”，也不能未经用户授权提高单杆收费。费用接收地址与实际发交易的服务钱包是两回事，目前尚未接入费用拨付服务。

未领取权益已经在合约中预留配额，领取无需再次处理历史区块或修改物种库存。迟领取不会让鱼种变化，也不阻塞后来批次。相比之下，尚未完成公共分配的批次可能需要历史证明，并按批次顺序恢复；这部分额外成本不包含在表格内。

7 项测试通过：1/50/51 人参与、收费失败和重入、历史证明恢复、永久预留及批量领取原子性、鱼获记录状态适配。记录适配模块有中英俄日文案，尚未接入线上旧版页面。候选部署数据已更新、保持禁用；未发送部署交易、未修改线上合约配置。

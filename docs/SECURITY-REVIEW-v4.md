# v4 发布前安全检查

范围为本仓库代码和本地 MockVRF 测试，不是第三方审计或主网验收。

已落实：固定 200 万累计发行上限及五档/物种额度；无增发、代理升级、规则修改、管理员指定中奖者入口；名单封盘后才能请求 VRF，禁止同轮重请求；coordinator 独占熵输入；先保存熵，限 Gas 自调用；FIFO 固定库存顺序；20 张为批次上限；同轮唯一鱼获且两次实际铸造至少 10 区块；标准 ERC-721 转账；铸造无接收方回调。

测试覆盖：准确库存、重复参与、封盘、授权和零费用、乱序回调、重复回调、单轮唯一中奖者、20% 筛选、批次独立性、延迟回调铸造间隔、暂停恢复、最后一枚、转账及网页接口。真实 VRF、源码公开验证和完整部署参数核验须在部署后完成。

保留边界：多地址/重复参与可消耗补贴；VRF/订阅停用可阻塞队首；需要交易触发而非自动时钟；额外 Gas 冷却/批次导致延迟；不可升级意味着发现漏洞时只能暂停新参与并迁移新合约；图片托管内容不由目前合约锁定。管理员仍可暂停入口，不能把本合约描述为完全无管理员或绝对安全。

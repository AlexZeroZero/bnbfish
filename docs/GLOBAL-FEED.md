# 全网鱼讯

已部署到 https://bnbfish.trade ，release：20260915-global12。

全网范围为当前游戏合约。接口 /api/global-catches 读取已确认的铸造数量、物种数量及最近 12 次原始钓获，转账不计作新钓获。快照延后 3 个区块，共享缓存 12 秒；支持增量更新和链重组重建。更新失败保留旧数据并标记延迟，首次读取失败不显示虚假零值。

服务端独立读取 RPC 默认使用 https://bsc-rpc.publicnode.com，可用 BNB_FEED_RPC_URL 覆盖。关闭 JSON-RPC 批量封装，避免原节点批量响应缺失和限流；未改动玩家交易 RPC、合约或自动推进服务。RPC 返回的链 ID、协议规则及统计总和均需核验。

桌面左下角、手机水域工具下方默认收起，可展开最近上鱼与鱼种统计。支持中文、英文、俄文、日文。自身未完成上鱼展示的鱼获延迟揭晓，避免提前剧透。

核验时：18 份 NFT，15 个种类，种类数量合计 18。公开接口、资源哈希、SRI 和 CSP 校验通过；7 项缓存、重组、本地化和交易安全测试通过。
